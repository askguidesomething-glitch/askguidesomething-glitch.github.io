# Dajaun Legette — Cybersecurity Portfolio

A static cybersecurity portfolio designed for GitHub Pages.

## Files
- `index.html` — portfolio page
- `styles.css` — visual design
- `script.js` — navigation and small interactions

## Before publishing
Replace:
- `YOUR-EMAIL@example.com`
- `YOUR-GITHUB-USERNAME`
- `YOUR-LINKEDIN-USERNAME`
- placeholder certification statuses
- starter project descriptions with your real work

## GitHub Pages
For a personal GitHub Pages site, the repository should be named:
`YOUR-GITHUB-USERNAME.github.io`

Then enable Pages from the repository's Settings → Pages and publish from the `main` branch. GitHub says the site can take a few minutes to appear.
